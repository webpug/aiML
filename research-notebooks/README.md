# Research-paper lessons

Executable reading companions that separate a paper's reported evidence from educational demonstrations.

## Lessons

- [01 — Chain-of-Thought Prompting Elicits Reasoning in Large Language Models](01-chain-of-thought-prompting.ipynb) — Wei et al. (NeurIPS 2022). Compare direct and few-shot chain-of-thought prompting, inspect the paper's evidence and ablations, and run deterministic offline exercises. About 60–90 minutes; Python and basic prompting knowledge are enough.

  [![Open lesson 01 in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/webpug/aiML/blob/main/research-notebooks/01-chain-of-thought-prompting.ipynb)

The lesson requires Python and Matplotlib only. It runs without a GPU, network access, API key, or model download. It is an educational companion, not a reproduction; the paper did not release an official implementation repository.
